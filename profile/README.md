## What it does

- **The right-click answer.** See which program created a new file, when, for which user, and which program started it.
- **History by program.** Every file one program created, searchable, filtered and saved as a CSV file.
- **What your AI agent wrote.** A file written by `node.exe` also names the agent that started it, such as `claude.exe`.
- **Only the folders you choose,** on any drive in your computer.
- **Locks and delete alerts.** Lock a tracked folder against deletes, get a notification naming the program that’s deleting its files, or both.
- **Your history stays on your computer.** Only two checks go online: the update check and the license check.
